# Universal Deterministic AOP Mapper Ruleset

Use template PNGs as geometry truth, AI/CV as the image-understanding layer, and deterministic rules as the pass/fail brain. Rules are universal; garment manifests provide the geometry.

## Locked rules
- Protected focal content cannot get wrecked by seams, bleed, blur, folds, hems, cuffs, collars, plackets, zippers, pockets, crotch, or panel boundaries.
- Focals span panels only when adjacent panels complete them cleanly.
- Chopped-looking outputs fail.
- Pockets must match exact underlying art.
- Back panels default to supporting continuation, not random duplicate people.
